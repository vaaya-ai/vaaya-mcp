# Cursor

Copy `mcp.json` to `.cursor/mcp.json` in your project (or run
`npx @vaaya/mcp install`). Restart Cursor. The agent gains `consult` (priced
plan) and `use` (run one line of it under `max_cost_cents`).

Walkthrough with a first paid call and a refusal:
https://vaaya.ai/blog/cursor-agent-mcp-payments
